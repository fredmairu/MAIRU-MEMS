How to use MEMS

Practical guidance for the GM Fund Services office.

1. Executive Dashboard

Review action counts, overdue work, workstreams and recent correspondence at a glance.

2. Action Tracker

Create one record per accountable deliverable. Consolidate related work where the owner and workstream are the same, but keep different deliverables clear. Update the status and deadline when the facts change.

3. Correspondence Register

Log each incoming letter, record its sender and reference, assign responsibility, set response/event deadlines, and record feedback or closure.

4. Clickable dashboard cards and overdue actions

Select a dashboard card to reveal the records behind its count. Use the Overdue Actions tab for a consolidated list of all overdue items and export that list to CSV.

5. Invitations and event alerts

For invitations, select the Invitation category and record the event date, RSVP deadline, response and attendance status. MEMS flags pending responses, upcoming events and overdue RSVP dates in the correspondence dashboard and register.

6. Export and data portability

Export CSV files for spreadsheet review. Keep a regular export until cloud backups are configured.

7. Online multi-user use

This prototype currently runs in local demo mode. To make it a shared online system, create a Supabase project, apply the included SQL schema, add the project URL and anon key to config.js, and deploy the folder to a static host. Then create authorised user accounts. Do not place a service-role key in the browser.

Version 0.1 includes dashboard, action tracking, correspondence logging, search, filters, editing and CSV export. Cloud file attachments, scheduled email reminders, and role-specific permissions are next-phase features.
